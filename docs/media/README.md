# Toki Demo 素材

- `demo.gif`：20 秒、960×540、12 fps、循環播放，供 README 直接顯示；由 MP4 轉檔。
- `demo.png`：原生 AppKit 更名預覽截圖，1600 px 寬；視窗圓角外側透明，介面內容保持不透明。
- `demo.mp4`：20 秒、1920×1080、30 fps、無聲的介面截圖剪輯。
- `demo-poster.jpg`：影片預覽場景的穩定影格，亦寫入 MP4 第 0 影格。

## 畫面來源

使用當前 `Sources/App.swift`、`Core.swift`、`DropImportView.swift` 編譯原生 Demo 程式。產品程式碼未修改；暫時啟動入口自動載入 `Tests/Fixtures/Import/` 的合成素材副本，其他狀態透過原生 UI 實際執行。

兩個 JPEG 成功更名為 `20240229_123456.jpg` 與 `20240229_123456_1.jpg`，缺少日期的 PNG 保留原名。復原後，三個檔案的原始名稱與 SHA-256 均與來源一致。

系統選檔視窗的自動化確認在拍攝時受阻，因此匯入由 Demo 啟動入口完成。本素材不宣稱驗收了選檔視窗或 Finder 拖放。影片是原生介面截圖剪輯，不是連續螢幕錄影，也不是 HTML 仿製介面。

## 製作

使用 brag／Hyperframes 本機渲染，加入標題與鏡頭動畫。無音樂、音效或旁白。製作計畫、動畫專案與驗證報告已移至專案外封存；儲存庫只保留 README 使用的展示成品。
