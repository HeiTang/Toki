# Toki Demo 素材

以 `bd16587` 的原生介面截圖製作；2026-11-05 更新為 22 秒 v2 介紹影片。

- `demo.mp4`：v2 介紹影片，22 秒、1920×1080、30 fps、660 幀、H.264／AAC，含配樂與少量音效，無旁白。
- `demo-poster.jpg`：獨立設計的「別再叫它 IMG_4822。」封面，1920×1080，亦寫入 MP4 第 0 影格。

## 展示流程

1. 以「照片記得那天。檔名呢？」帶出檔名整理需求。
2. 展示 `IMG_4822.jpg` 轉為 `20240229_123456.jpg`。
3. 預覽並選取檔案，顯示原生更名確認視窗。
4. 展示完成結果與同名自動加序號。
5. 以復原後的原始檔名、Toki 圖示與專案入口收尾。

## 畫面來源與驗證

原始截圖從 `bd16587` 的 `Sources/App.swift`、`Core.swift`、`DropImportView.swift` 編譯獨立 Demo App 拍攝，產品原始碼未修改。Demo 啟動入口僅設定固定深色外觀與視窗大小，自動匯入 `Tests/Fixtures/Import/` 的合成素材副本；選取、更名、確認與復原都透過原生 UI 實際執行。

`IMG_4822.jpg`、`IMG_4823.jpg` 成功更名為 `20240229_123456.jpg`、`20240229_123456_1.jpg`；`no-date.png` 缺少有效拍攝日期而保留原名。復原後三個檔案的原始名稱與 SHA-256 均與來源一致。

本素材不宣稱驗收系統選檔視窗或 Finder 拖放。影片為原生介面截圖剪輯，不是連續螢幕錄影，也不是 HTML 仿製介面。確認視窗使用原生獨立截圖，剪輯時放大並疊於對應主視窗，以利閱讀。

## 製作

使用 brag／HyperFrames 本機渲染，加入大字標題、檔名轉換、介面特寫、節拍切場、配樂與音效。已通過 HyperFrames 執行、版面、音訊與文字對比檢查，並抽查實際編碼影格、影片規格與首幀封面。影片沿用既有原生操作截圖，這次剪輯未重新執行 App 驗收。

製作計畫、原生截圖、動畫專案與驗證資料保留於儲存庫外的工作目錄；儲存庫只收錄展示成品與此說明。
