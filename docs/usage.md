# 使用 Toki

建置後開啟 `dist/Toki.app`。最低 macOS 13，App 已內附 ExifTool，不需另外安裝。


## 加入檔案
- 從 Finder 拖入照片、影片、資料夾，或按「加入檔案或資料夾…」（⌘O）。
- 可多選、混合資料夾與個別檔案；每次加入會建立新一批預覽，不會立即更名。
- 重複路徑與重疊資料夾中的同一項目會去重。資料夾內不支援的檔案略過；明確選取不支援項目或符號連結會拒絕並保留原批次。
- 子資料夾是否展開依「設定 > 掃描 > 包含子資料夾」。
- 僅改各檔案在原資料夾中的名稱，不搬移媒體。多來源的復原紀錄存放位置會在確認時明示。
- 掃描、執行與對話框開啟時不接受新的拖入項目。

## 自訂命名
由「設定…」（⌘,）的「命名」頁編輯範本；不是獨立工具列按鈕。
{yyyy} 年、{MM} 月、{dd} 日、{HH} 24 小時、{mm} 分、{ss} 秒。
{name} 原檔名（不含副檔名）、{index} 至少四位的流水號。
可加入一般文字，例如：
旅行_{yyyy}-{MM}-{dd}_{index} → 旅行_2024-02-29_0001.jpg
{yyyy}{MM}{dd}_{HH}{mm}{ss}_{name} → 20240229_123456_IMG_0001.jpg

副檔名會自動保留，範本不需自行加上 .jpg；同名自動加 _1、_2。
流水號初次依原始完整路徑排序，在本次匯入與重掃內保留；重新匯入視為新的批次。
命名日期沿用既有拍攝時間／QuickTime 時區解讀，不用 Finder 建立時間取代拍攝日期。
沒有有效日期的檔案仍保留原名，即使範本只有原檔名／流水號亦同。
設定提供範例、變數說明、錯誤提示、回復預設；取消不保存，套用才保存命名偏好並建立預覽。
不允許未知變數、空規則、路徑分隔字元或控制字元。範本最多 200 UTF-8 位元組，新檔名含副檔名與同名序號最多 255 位元組；不合法結果不會列為可執行。

## 執行
檢查預覽、狀態與更名範圍，再按「重新命名…」並確認。完成後可復原。
只改檔名，不改寫媒體內容；復原紀錄不是備份。XMP／AAE 與 Live Photo 配對未新增連動。
主題入口保留「顯示／更多動作 > 外觀」，提供跟隨系統、淺色、深色。


## 手動測試素材

`Tests/Fixtures/Import/` 是合成素材，可複製到暫存資料夾後練習匯入、同秒碰撞、自訂命名與復原。請勿直接更名儲存庫內的素材。

## 已知限制

本機建置採 ad-hoc 簽章、未公證。跨版本 macOS 與 Intel 尚未實機驗證。XMP／AAE 與 Live Photo 配對不會連動更名。
