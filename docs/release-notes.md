## Toki 1.5.0

這次更新重新整理原生 macOS 介面，讓更名預覽、檔案選取與命名設定更清楚。

### 本次更新

- **更名預覽介面**：採用緊湊清單與原生狀態篩選；清單與檔案資訊維持穩定底色，工具列跟隨 macOS 系統外觀。
- **命名設定**：命名格式集中在「設定 → 命名」，使用原生分頁與變數選單，方便編輯範本並檢查範例。
- **檔案操作**：檔案右鍵選單可複製路徑；選取項目後，主要更名按鈕顯示實際作用範圍。
- **使用文件**：更新 22 秒介紹影片、產品封面與 README，並補充專案維護說明。

### 版本與限制

- 版本 **1.5.0／build 26**。
- 本版使用 **ad-hoc 簽章，尚未完成 Apple 公證**；首次開啟可能需要依下方說明允許執行。
- 只修改檔名，不改寫媒體內容；復原紀錄不是媒體備份。
- XMP／AAE 與 Live Photo 配對不會連動更名。

## 下載與安裝

適用於 **Apple Silicon（M1 或更新）／macOS 13 以上**。

1. 下載下方的 **Toki-macos-arm64.dmg**。
2. 開啟 DMG，將 **Toki.app** 拖到 **Applications**。
3. 從「應用程式」開啟 Toki。

App 已內附 ExifTool，無須安裝 Homebrew。

也提供 ZIP；解壓後將 Toki.app 移至「應用程式」。`SHA256SUMS.txt` 可供校驗下載檔案。

> 「Source code」是開發用原始碼。一般使用者請下載 DMG 或 ZIP。
